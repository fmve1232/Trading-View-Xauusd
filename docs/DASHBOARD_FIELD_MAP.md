# Dashboard field map: the terminal band (sections A-I)

Generated by `audit/tools/dashboard_field_map.py` from `site/bbg.js` (`FIELDS`, `GAPS`); `--check` confirms this file matches the code. Mandate 2026-11-28, Parts 18-19. The band is display only: `bbg.js` lays out what the pipeline published in `data/<tf>.json` and `data/index.json`, and what `app.js` already derives (freshness, the live quote, the RECORD verdict, the WAIT wording, the trend-vote wording, the MT5 offset), which it is handed. It computes no signal, score or probability.

Status words, used whenever a value is missing or unvalidated: `N/A`, `UNAVAILABLE`, `DELAYED`, `UNTESTED`, `STALE`; also `INDICATIVE` (futures standing in for spot), `CLOSED` (market shut) and `SYNTHETIC` (simulated data).

Field paths are in `data/<tf>.json` unless they start with `alerts.` (that is `data/index.json`).

'Each engine run' = the pipeline's 15-minute schedule; the page picks a new run up within 20 s, re-renders the band every 15 s, and at most once a second while live quotes arrive.
